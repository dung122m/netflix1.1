# Component Inventory - Netflix Vietnam

## Shared Same-Site Components
- **HeaderNavbar**: Contains Netflix Logo (SVG), LanguageSelector (select dropdown), and SignInButton (red button).
- **LanguageSelector**: Dropdown component that lists English & Vietnamese.
- **EmailSignUpForm**: Consists of an email input (with float-label animation on focus/filled) and a large red CTA button ("Bắt đầu" / "Get Started" with chevron-right icon).
- **DividerLine**: High-contrast dark grey thick band (height: 8px, background-color: #232323) separating landing page sections.

## Feature Components
- **HeroBanner**: Big background image with radial black gradient overlay, hosting the header and the main marketing text.
- **FeatureRowTV**: 2-column flex row with TV bezel image and an auto-playing mp4 video layer.
- **FeatureRowDownload**: 2-column flex row with mobile phone image, and an absolute-positioned floating "Downloading card".
- **FeatureRowWatch**: Simple 2-column row showcasing "Watch everywhere".
- **FeatureRowKids**: 2-column row with "Create profiles for kids" pairing kids image and text.
- **FAQSection**: Contains a title and an accordion list with 5-6 frequently asked questions.
- **FooterSection**: Multi-column links with muted text, another LanguageSelector, and a small locale label.
