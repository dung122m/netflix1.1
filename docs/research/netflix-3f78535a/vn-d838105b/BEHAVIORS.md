# Interactive Behaviors & Animations - Netflix Vietnam

## 1. Floating-Label Input (EmailSignUpForm)
- **Trigger:** Focus on the input field OR when the input is non-empty.
- **Transition:** Label text slides up, shrinks font-size, shifts opacity (0.2s ease-in-out).

## 2. FAQ Accordion Panels
- **Trigger:** Click question bar.
- **Transition:** Answer panel expands in height (smooth slideDown). "+" sign rotates 45 degrees to "x".

## 3. Inline Video Playbacks (FeatureRowTV)
- **Mechanism:** Muted, autoplaying video in TV bezel, perfectly aligned via absolute positioning.

## 4. Floating Download Card Animation (FeatureRowDownload)
- **Animation:** Absolute-positioned overlay card with a thumbnail. Progress shows animated sprite/SVG.
